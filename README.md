# Слежка за сайтами

Каждые 5 минут GitHub Actions проверяет сайты из `sites.txt`.

- Сайт не ответил 3 раза подряд → открывается задача «🔴 … не отвечает» на владельца (письмо + уведомление в приложении GitHub). Поднялся → задача закрывается сама.
- SSL-сертификат истекает меньше чем через 14 дней → задача-предупреждение.
- Текущее состояние — в `status.md` и во вкладке Actions.

Новый сайт — добавь адрес строкой в `sites.txt`. Проверить сейчас: Actions → «Проверка сайтов» → Run workflow.
